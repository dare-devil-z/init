# AuroraCalc

A modern, responsive calculator web app with keyboard support, light/dark mode, and a polished glassmorphism UI.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Host publicly (free)

### Option A — Netlify Drop (fastest)
1. Go to https://app.netlify.com/drop
2. Drag-and-drop this project folder.
3. Netlify instantly gives you a public URL.

### Option B — Cloudflare Pages
1. Push this folder to a GitHub repo.
2. In Cloudflare Pages, create a new project and connect the repo.
3. Build command: *(leave empty)*
4. Output directory: `.`
5. Deploy.

Because this environment has no persistent cloud account credentials, automatic production deployment cannot be finalized from here.
